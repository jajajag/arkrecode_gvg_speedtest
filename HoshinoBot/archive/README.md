# 已归档的 HoshinoBot 实现

此目录保存精简前的源码快照，供查阅和恢复，不作为插件入口加载。

- `gvg.py`：旧指令注册及图片情报处理。
- `queries.py`：胜率表、错题本、一速记录、信息、历史，以及旧版作业和玩家面板。
- `database.py`、`api.py`：旧情报归档、图片下载和图片清理实现。
- `frame_buffer_ark.py`：未被现有插件引用的 Windows 窗口捕获工具。

快照保留原相对导入，不能直接在本目录运行。恢复时应结合当前数据结构迁回对应模块。
已有数据库中的旧情报表、字段和图片不会被删除。新建数据库只创建核心功能需要的表与字段。
团战测速、团战总结、乱速仍在原入口注册；清日常和更新数据继续使用现有流程。
